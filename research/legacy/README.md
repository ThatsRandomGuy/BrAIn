# Historical research

These benchmark and example drivers belong to the earlier structured reasoning
prototype. They are retained for provenance and exploration, not run as current
pixel-memory tests. Their imports are pointed at `core/` in this repository.
Some live comparisons require an explicitly configured external model.

The initial 50-prompt comparison is development evidence, not proof that pixels
reduce context cost. See the current [results](../../docs/results.md) and
[testing policy](../../docs/testing.md) before interpreting historical reports.
